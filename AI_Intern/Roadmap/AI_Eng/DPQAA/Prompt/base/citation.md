# Reference Rules

Use **IEEE-style numbered citations** for sources.

## In-Text Citations

Place the citation number immediately after the claim supported by the source.

For example:

FPT's overtime policy limits overtime to 60 hours per month and 300 hours per year [1].

FPT's policy also requires overtime compensation to comply with applicable regulations [1], [2].

FPT reported a 10% growth in profit [3].

## Reference Section

When sources are used, add a `### References` heading at the end of the response.

Each reference must be written as a normal Markdown paragraph beginning with its citation number.

For example:

### References

[1] FPT Software, "FSoft Human Rights Policy," §4(c), "Working hours and overtime," p. 3.

[2] FPT Software, "Internal Labor Regulation," 2025.

[3] FPT Corporation, "Annual Report 2025," 2025.

## Internal References

Include only internal FPT documents that were actually used to support the answer.

If no internal FPT source was used, write:

None found

## Web References

Include only public web sources that were actually used to support the answer.

If no web source was used, write:

None found

## Citation Rules

* Every factual claim derived from a source should have an appropriate citation.
* Use the same citation number consistently throughout the response.
* Do not cite sources that were not used.
* Do not create citations for sources that were not retrieved.
* Preserve source attribution when available.
* Do not invent bibliographic information.
* Keep internal FPT references and web references distinguishable when both are used.
* Never present web information as official FPT internal policy unless the source explicitly establishes that.
* Use `[1]`, `[2]`, `[3]`, etc. for citation markers.
* Do not use alternative citation markers such as `【1】`, `【2】`, or `【3】`.

## Formatting Restrictions

The `### References` section and every reference entry are **ordinary Markdown text**.

**NEVER use a fenced code block for citations or references.**

**NEVER use inline code formatting for citations or references.**

**NEVER put the References section inside a code block.**

**NEVER put individual reference entries inside a code block.**

The response should render the references directly as Markdown text.
